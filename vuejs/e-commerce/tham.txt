- Radius Small (Badges)      : 8px

4. BREAKPOINTS & RESPONSIVE GRID LAYOUT
--------------------------------------------------------------------------------
- Mobile (< 640px)           : 1 - 2 Kolom (compact, spacing: 12px)
- Tablet (640px - 1024px)    : 3 Kolom (spacing: 16px - 20px)
- Desktop (>= 1024px)        : 4 Kolom (spacing: 24px, max-width: 1280px centered)

5. KOMPONEN KONSISTEN (UI/UX RULES)
--------------------------------------------------------------------------------
A. Filter Kategori (Pill Tabs):
   - Scrollable horizontal di mobile tanpa scrollbar jelek (`scrollbar-width: none`).
   - Active state: background primary oranye, text putih, subtle shadow.
   - Inactive state: background putih / slate-100, border halus.

B. Kartu Produk (Product Card):
   - Gambar selalu dengan aspect-ratio 4:3 atau 1:1, object-fit: cover.
   - Hover effect: gambar zoom perlahan (scale 1.05) tanpa keluar frame (overflow: hidden).
   - Floating badge di atas foto (kiri: Promo/Diskon, kanan: Level Pedas 🌶️).
   - Judul produk dibatasi max 2 baris (line-clamp: 2).
   - Tombol "+ Tambah" selalu konsisten di pojok kanan bawah tiap kartu.

C. Search Bar:
   - Input bersih dengan icon pencarian (🔍), rounded-full, border fokus oranye lembut.

D. Feedback State:
   - Loading State: Skeleton shimmer effect (bukan sekadar teks "loading").
   - Empty State: Ilustrasi emoji / icon ramah dengan ajakan reset filter.
