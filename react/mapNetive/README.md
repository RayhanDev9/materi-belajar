# MapNetive

Aplikasi peta dan navigasi berbasis Expo, React Native, dan TypeScript.

## Menjalankan proyek

```bash
npm install
npx expo start
```

Halaman dan route berada di `src/app` menggunakan Expo Router. Komponen yang dapat digunakan
kembali berada di `src/components`.

## Pemeriksaan kode

```bash
npx expo lint
npx tsc --noEmit
```
